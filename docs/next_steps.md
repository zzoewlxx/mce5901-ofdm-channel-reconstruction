# 后续研究思路（2026-11-10）

结论都基于验证集 run 0056，测试集 run 0057 仍未使用。

## 1. 已经知道的事

| 发现 | 依据 |
|---|---|
| 无噪声导频时任务太简单：线性插值约 −43 dB，已到测量误差水平 | `experiments/00_pilot_2026-11-06` |
| 加噪声后，LMMSE 比线性插值好约 4–10 dB（8 或 16 个导频），配对 95% 置信区间约 ±0.1 dB | `results/20261106-0713_auto_baselines-val` |
| **3.1 MHz 的 64 子载波块里，信道实际只有约 2 维**：协方差的第 1 个特征值占 99.5% 能量，前 2 个占 99.99% | 本文第 3 节 |
| 用全量数据训练的 MLP（2×128）在 0–20 dB 与 LMMSE 相差不到 0.2 dB，30 dB 时差 1.0–1.5 dB<br>• 按期望误差加权损失，可把 30 dB 的差距减半<br>• 换成 3×256 的大网络没有帮助<br>• 残差变体与 LMMSE 几乎持平（差约 0.002 dB）<br>• 没有任何变体显著优于 LMMSE <br>（验证实验：16/8 个导频、随机种子 0、各 15 轮） | `results/20261110-1734_auto_mlp-val` |

**LMMSE 为什么强（一个可能的解释）：** 协方差能量集中在约 2 个模式上，重建 64 个子载波近似于从 n 个带噪声的导频里估计约 2 个复系数。按这个去噪直觉，低 SNR 下的增益量级约为 10·log10(n/2) dB。这只是粗略估计，不是相对线性插值的严格公式；严格做法是用训练协方差分别算两种线性估计器的理论均方误差。

| 导频数 n | 直觉估计 | 实测增益（0 dB） |
|---|---|---|
| 16 | 9 dB | 9.7 dB |
| 8 | 6 dB | 7.3 dB |
| 4 | 3 dB | 5.0 dB |

这个解释在汇报问答时有用，但要注意边界：LMMSE 是最优的**线性**估计器，只有在信道和噪声联合高斯等条件下才是所有估计器里最优的。所以准确的说法是"本次验证中所测试的模型没有显著超过 LMMSE"，不能说神经网络一定赢不了，也不能排除训练不充分。

## 2. 主线还要补完的实验（M2–M3）

1. **MLP 多随机种子。** 用 3 个随机种子重跑 `02_mlp_fulldata` 中的普通 MLP 和加权损失版本，报告均值和波动。

   目前只跑了种子 0，每个 2×128 模型在 CPU 上训练约 2–4 分钟。加权损失改善了高 SNR、牺牲了一点低 SNR；大网络在相同训练轮数下没有改善。高 SNR 误差底的原因（损失函数、容量、优化还是训练轮数）还没有定论，可以加一组"训练更久"的对照。

   同时补上 4 个导频的 MLP。
2. **噪声功率失配。** 对照必须公平：给 LMMSE 和带 SNR 输入的 MLP 同样的错误 SNR；不输入 SNR 的盲 MLP 单独列为一种方法。在真实 SNR 0–30 dB 下比较最坏情况的损失。
3. **误码率（可选）。** 用估计出的信道对 QPSK/16-QAM 做迫零均衡，看 1–2 dB 的 NMSE 差距在误码率上是否重要。
4. **复杂度。** 每次估计的乘加次数：LMMSE 只输出待估系数时，16 个导频约 48×16、8 个导频约 56×8 次复数乘加；MLP 约 3.3 万次实数乘加。再加上 CPU 推理时间。
5. **测试集。** 所有方案定稿后，在 run 0057 上只跑一次，作为报告里的最终数字。验证集的奇数块已经被反复查看，不能代替它。
6. **稳健性检查。** 把 bootstrap 的分块长度从 50 个快照改成 25 和 100，确认置信区间结论不变。
7. **工程改进。** 训练时保存模型权重，方便事后重新评估。

## 3. 可选扩展（待验证的假设）：天线和频率联合重建

信道在不同情形下的维数（训练集统计，按能量占比数特征值个数）：

| 情形 | 90% 能量 | 99% 能量 | 99.9% 能量 |
|---|---|---|---|
| 单天线，64 个子载波（当前题目） | 1 | 1 | 2 |
| 32 根天线，单个子载波 | 17 | 27 | 31 |
| 32 根天线 × 64 个子载波联合 | 17 | 28 | 42 |

联合起来以后，线性维数约 28。但决定信道的物理量其实只有发射机的二维位置（再加上朝向），也就是说，信道落在一个低维的**非线性**曲面上。DICHASUS 团队的 channel charting 工作就是利用这一点。LMMSE 只能利用线性子空间，神经网络原则上可以利用非线性结构。但这只是假设：朝向、环境变化、同步和测量误差也会影响 CSI，不能保证 MLP 会赢。

可以做的实验：只在少数天线、少数子载波上放导频，比如 8 根天线 × 8 个子载波，重建全部 32 × 64 个系数。比较 LMMSE（2048 维协方差，用训练集估计）和 MLP 的表现，看导频越稀疏时谁更好。

代价：数据要重新抽取，现有 npz 已经包含全部 32 根天线，可以直接用；模型输入输出都更大，CPU 上仍然可以训练。

优先级低于第 2 节的主线实验。时间允许就作为报告里的"进一步实验"，否则作为汇报的 future work。

## 4. 其他可选方向

- **跨环境泛化。** 在 dichasus-015x（室内视距实验室，参数相同）上测试 005x 训练出的模型和协方差，看统计失配时谁下降得更多。只需下载一个 run，约 3.5 GB。
- **更宽的频带。** 用 256 个子载波（12.5 MHz）的块，信道维数会变高，导频间隔接近相干带宽时，插值和 LMMSE 都会变难。

## 5. 汇报故事线建议（10 分钟）

1. **问题与动机**（约 1 分钟）：导频开销与估计精度之间的取舍。
2. **数据**（约 1.5 分钟）：DICHASUS 真实测量数据；信道在频率上非常平滑（图 a）。
3. **为什么研究含噪导频**（约 1 分钟）：无噪声时所有方法都一样好。
4. **方法**（约 2 分钟）：线性和样条插值、LMMSE（等价于岭回归）、MLP 和残差变体。
5. **结果**（约 3 分钟）：NMSE–SNR 曲线；MLP 相对 LMMSE 的差距；用"信道只有约 2 维"解释原因。
6. **评估中的坑与结论**（约 1.5 分钟）：坏快照筛选、归一化泄露、学习方法什么时候可能有用（第 3 节）。
