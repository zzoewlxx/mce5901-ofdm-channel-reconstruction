# results/

每次正式运行一个文件夹：`<YYYYMMDD-HHMM>_<成员拼音>_<实验名>/`，由 `src/runlog.py` 的 `save_run(...)` 自动生成。

文件夹里应该有：
- `run.json`：实验配置、指标、git commit、运行命令、Python 和 numpy 版本、备注
- 结果图（PNG）或小表格（CSV/JSON），单个文件不超过 5 MB

规则：
- **只提交小文件。** 原始数据、`.npz`、模型权重都不进 git，`.gitignore` 已经屏蔽。
- **先提交代码再跑正式实验。** 这样 `git_commit` 才对得上；如果 `run.json` 显示有未提交改动，这次结果不能写进报告。
- **调参只看验证集 run 0056。** 测试集 run 0057 只在最终评估时跑一次，结果文件夹名里写上 `test`。
- **不要修改或删除别人的结果文件夹。** 要重跑就新建一个。
