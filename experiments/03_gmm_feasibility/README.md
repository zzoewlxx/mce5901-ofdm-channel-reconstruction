# 03 GMM 可行性试跑（2026-11-19）

**要回答的问题：** 文献中在实测数据上赢过 LMMSE 的高斯混合（GMM）估计器，在我们的数据上有没有用？在什么情形下有用？

**结论：** 在 64 子载波单天线这个原题目里，GMM 和 LMMSE 几乎没有差别（+0.00 到 +0.02 dB），即使"作弊"用上真实位置也最多 +0.36 dB。这和 MLP 的结果一致：这个任务里 LMMSE 已经接近天花板。一旦把天线维度加进来，GMM 稳定、显著地优于 LMMSE：
- 32 天线去噪：0 dB 时好 +2.8 dB；
- 天线 × 频率联合重建：0 dB 时好 +1.5 dB；
- 只在部分天线上有导频：好 +2 到 +6 dB。

这支持把扩展做成"学习方法在什么条件下比 LMMSE 有用"。

> 只用了验证集 run 0056（偶数块用来选超参数，奇数块用来报告），测试集 run 0057 没有加载。
> 这是可行性试跑，结果直接存在本文件夹，没有走 `results/` 的 `save_run` 流程。结果文件都由本文件夹中的代码生成，运行之后代码没有改动过。

## 方法

- **GMM 估计器**（Turan, Fesl, Grundei, Koller, Utschick, arXiv 2207.14150；在 64 天线实测数据上优于样本协方差 LMMSE）。
  - 离线：在干净的训练信道上用 EM 拟合 K 个复高斯分量（零均值，因为每个快照的公共相位是随机的，信道均值的功率只有总功率的约 5e-5），每个分量向全局协方差做少量收缩 α。
  - 在线：对每个分量做一次 LMMSE，再按后验概率 p(k|y) 加权求和。K=1 时就是普通 LMMSE。
- **LMMSE**：训练集的全局样本协方差，对角加载系数在偶数块上选择。在 64 子载波设置下，与 `results/20261106-0713_auto_baselines-val` 的数字相差不超过 0.03 dB。
- **位置分格（cell-genie，只作诊断）**：按训练集中发射机位置用 k-means 把房间分成 16 或 64 格，每格一个协方差，测试时用**真实位置**选格。它不是可用的接收机，用来估计"利用位置结构"最多能带来多少。另一个变体再加上发射机朝向。
- GMM 和分格方法只用 EM 子样本（freq64 用 20 万条），LMMSE 用全部训练向量，这样的设置对 GMM 偏保守。

## 三种设置

| 设置 | 一个样本 | 维度 | 线性有效维数（90/99/99.9% 能量） | 导频 |
|---|---|---|---|---|
| freq64（原题目） | 单天线，64 个子载波 | 64 | 1 / 1 / 2 | 16、8、4 个子载波 |
| space32 | 单子载波，32 根天线（取块内 8 个子载波作为样本） | 32 | 17 / 27 / 31 | 全部 32 根（纯去噪）、16 根、8 根（天线编号步长 2 / 4） |
| spacefreq | 32 根天线 × 16 个子载波（64 块中每隔约 4 个取一个） | 512 | 17 / 28 / 43 | 32 天线 × 4 子载波、8 天线 × 4 子载波 |

NMSE 只在非导频位置上计算（全部位置都是导频时按全部位置算）。增益是"比 LMMSE 好多少 dB"，95% 置信区间来自配对的分块 bootstrap（50 个快照一块，52 个报告块）。

## 怎么解读

1. **GMM 的收益和信道维数、结构直接相关。** 64 子载波的块实际只有 1–2 维，用真实位置也挖不出东西。天线维度有约 27 维，而且不同位置的协方差差别很大，局部协方差的加权组合明显优于单一的全局协方差。
2. **低 SNR 时收益最大，高 SNR 时趋近 0。** 这和 Turan 等人论文中的规律一致：先验越重要，结构化先验的价值越大。
3. **只在部分天线上有导频时（相当于减少下行导频端口），收益最大（+2 到 +6 dB）。** 但这种情形下 LMMSE 和 GMM 的绝对误差都偏高（−1 到 −9 dB），汇报时要同时给出绝对值。
4. **在 512 维的联合设置下，GMM 受训练数据限制。**
   - 每个快照算一个样本，只有约 1.5 万个样本；K=16 的 EM 两轮就收敛了，实际上相当于"k-means 分类 + 每类一个协方差"。
   - 被选中的配置在网格边上（K 最大、收缩最小）。
   - 位置分格的诊断值约为 GMM 的两倍，说明还有空间。

## 局限

- 训练集和验证集来自**同一个房间**的不同测量 run，发射机走过的区域相同。GMM 学到的是"这个房间里各位置的协方差"，换环境是否还有收益没有测试（可以用 dichasus-015x 测）。
- EM 和噪声只用了一个随机种子；只测了一组 K 和 α。
- 天线子集用编号步长选取，没有按阵列几何优化。

## 建议的下一步（如果小组采用这个扩展）

1. **结构化 GMM：** 每个分量的协方差用 C_空间 ⊗ C_频率（Kronecker 积），参数从 512² 降到 32² + 16²，在 1.5 万个样本下应能支持更大的 K。论文里的 Toeplitz、循环结构也是同一思路。
2. **在同样的联合设置下训练 MLP**（输入 128 个导频，输出 384 个系数），回答"一般的神经网络能否也利用这种结构"。
3. **复杂度：** GMM 每次估计约为 K × (m² + d·m) 次复数乘加（m 是导频数，d 是维数）。按 32 天线 × 4 子载波、K=16 粗算，约为 LMMSE 的 20–30 倍，需要实测 CPU 时间。
4. 所有方案定稿后，在 run 0057 上只跑一次。
