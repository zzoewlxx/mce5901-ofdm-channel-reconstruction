PROTOCOL

A protocol that cannot flatter the learned model

One global scale

Normalising each snapshot by its own power leaks the channel norm. In our first check it made the MLP look 1–2 dB better than LMMSE.

Select and report on different blocks

Even 50-snapshot blocks of the validation run choose every setting; odd blocks give the reported numbers.

Paired block bootstrap

Both methods are scored on the same resampled blocks and the same noise; we report a 95 % interval of the dB difference.

Frozen before the test

Methods and the judging rule were fixed first: “better” means the interval excludes zero and the gain is at least 0.1 dB. The test run was evaluated once.

Most of our effort went into a fair protocol. First, one global scale: when we normalised each snapshot by its true power, the network learned the channel norm for free and looked one to two dB better than LMMSE. That gain disappeared with a fair scale. Second, we never report on the blocks we used for choosing settings. Third, all comparisons are paired, with confidence intervals from a block bootstrap, because neighbouring snapshots are correlated. Fourth, before touching the test run we froze the list of methods and the rule for calling something better. (About 60 seconds.)
