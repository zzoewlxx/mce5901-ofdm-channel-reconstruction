RESULT 3 · TEST RUN, 16 PILOTS

A wrong SNR hurts LMMSE; a blind MLP needs none

Assuming the SNR 10 dB too low costs LMMSE 2.1–2.4 dB; 10 dB too high only 0.7 dB. The blind MLP stays within about 0.3 dB of the LMMSE that knows the SNR, up to 20 dB.

LMMSE needs the noise power. What if it is wrong? On the left, the loss against the offset between assumed and true SNR. It is asymmetric: assuming too much noise makes the estimator smooth away real signal, which costs up to 17 dB; assuming too little noise only lets more noise through. On the right, an LMMSE designed for 20 dB loses 2.3 dB when the true SNR is 0 dB. The blind MLP, which never sees the SNR, stays within about 0.3 dB of the ideal LMMSE up to 20 dB. So the one real advantage of the MLP in this setting is robustness, not accuracy. (About 60 seconds.)
